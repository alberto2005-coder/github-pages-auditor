# Política de seguridad / Security policy

Si encuentras una vulnerabilidad, **no abras un issue público**: usa *Security → Report a vulnerability* en GitHub.
If you find a vulnerability, do **not** open a public issue: use *Security → Report a vulnerability* on GitHub.

La herramienta solo envía el token a `api.github.com` y nunca lo guarda. / The tool only sends the token to `api.github.com` and never stores it.
